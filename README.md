## **THE WEATHER**

A simple installable progressive web app that shows real time weather in any location. It is lightweight, responsive and even works offline.

## **Live Demo**

[Check it out](https://weather-nine-mu-58.vercel.app/)

## **Features**

- Current Weather Data - Temp, description, humidity, wind speed...
- Search by city
- Offline support - caches previous data and pulls information out of them.
- Installable - Add to home screen or desktop
- Responsive - works on all devices
- Forecast - shows weather for next 24 hours / 5 days

## **Tech Stack**

- Frontend: HTML, CSS && JAVASCRIPT
- BACKEND: NODE && EXPRESS
- Caching: JAVASCRIPT (service worker)
